# Manuscript

`paper.pdf` is the final 27-page submission by Malhar Alpesh Patel and
Luiza Cristina Corpaci, including the NeurIPS Paper Checklist on pages 21–27.
The checklist is retained as part of the submitted research record.

The PDF was copied from the clean LaTeX export supplied locally as
`Semantic_Drift___SPS_Apart_Research_Neurips_Vericodegen-5.pdf`.
Its title page, abstract, release information, and appendix structure agree
with the final submission supplied for this repository review. The latter
browser-printed copy has damaged text/glyphs, so it is not used here.

The tracked `paper.tex`, `checklist.tex`, and figure files are from an earlier
submission. They are retained for provenance but do **not** reproduce the
final PDF. Matching final LaTeX source is still needed before claiming a
reproducible manuscript build. Local drafts are not part of the public source.

The paper's code/data archive is
[doi:10.5281/zenodo.23392977](https://doi.org/10.5281/zenodo.23392977).
The archive DOI is not presented as a separate DOI for the paper.
